The web app (port 3000) is running, but nothing is listening 
on port 8787, where it looks for the game server. 
Start the game server in a second terminal:


cd ~/Desktop/Oxude && npm run serve -- --migrate --memory

Leave it running, then reload the page. The status should 
change from "Connecting" to "Live", and agents 
should appear within a few seconds.

--memory uses a throwaway in-memory database, so agents 
and matches are lost when you stop the server. 
To keep data between runs, point it at your Postgres instead:


cd ~/Desktop/Oxude && DATABASE_URL=postgres://... npm run serve -- --migrate
